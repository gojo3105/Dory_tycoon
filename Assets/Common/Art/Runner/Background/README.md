# 배경 레이어 (2026-09-08 반입)

사용자가 올린 야경 플랫포머 팩 33장 중 배경용 21장. **아직 씬에 연결 안 됨** —
`ParallaxBackground.cs`는 있는데 `SceneGenerator`가 만들어주지 않는다 (`CODEX-BGWIRE1`).

## 레이어 순서 (먼 것 → 가까운 것)

| 파일 | 역할 | 원본 크기 | 스크롤 비율 제안 |
|---|---|---|---|
| `sky.png` | 하늘. **유일하게 투명이 없다** — 맨 뒤에 깔린다 | 1920x1079 | 0.0 (고정) |
| `mountain1~4.png` | 먼 산 실루엣. 아주 어두운 남색 | 159~343 x 238~459 | 0.15 |

- `_front` 붙은 것은 **캐릭터 앞에** 그린다. 색이 더 진해서 뒤에 두면 중간 레이어와 구분이 안 된다.
- 산은 채도가 거의 없는 실루엣이다. 하늘 위에 겹치는 용도이지 단독으로 보이는 그림이 아니다.

## 주의: 이 폴더는 아직 임포트 설정이 없다

`SharedArtImporter`가 `Assets/Common/Art/` 아래 모든 파일에 **PPU 64 + Point 필터**를
기본으로 찍는다. 이 팩은 픽셀아트가 아니라 매끈한 벡터풍 그림이라
**Point로 확대하면 곡선이 계단처럼 깨진다.** Bilinear이어야 한다.

고치는 건 `CODEX-ARTIMPORT1`. 그 전까지는 이 폴더 그림을 씬에 넣지 말 것.
